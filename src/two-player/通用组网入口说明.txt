影子诡局联机模组 · 公开测试版
S20-20261113-checkpoint-retry

这是非官方双人联机测试版，仍需实机测试，不是稳定正式版。
两台电脑都需要安装游戏和同一版模组，游戏版本及所需 DLC 内容应一致。

一、首次安装
1. 正常退出游戏，完整解压 OneClick ZIP 到任意文件夹。
2. 双击 Install.cmd 或「一键安装.cmd」。它会查找 Steam 游戏目录；找不到时选择包含 ShadowGambit_TCC.exe 的文件夹。
3. 安装完成后会复制 Steam 启动选项并显示说明。Steam → 游戏属性 → 通用 → 启动选项，粘贴一次即可。
4. 以后从 Steam 启动，选择「单人游戏 / Single player」「创建房间 / Host a room」或「加入房间 / Join a room」。
若没出现设置窗口，双击游戏目录中的 ShadowGambitCoop/Setup-Steam.cmd，再粘贴启动选项。

完整包内置 Python 3.13.9 x64、BepInEx 和 Unity 2021.3.25 基础库，无需单独安装 Python 或修改 PATH。
首次启动仍需在本机生成接口缓存，可能比以后慢。控制台默认隐藏，日志照常记录。
安装器会校验文件并备份被覆盖的文件；不会安装附带存档。本包不含作者的个人进度、地址历史或房间信息。
框架备份位于游戏目录 ShadowGambitCoop/backups/easy-install-*。

二、已有模组的覆盖更新
两端都退出游戏，将 Update ZIP 解压到游戏根目录并覆盖同名文件，不能只换 DLL。
Update 包不含框架和 Python，首次安装请用 OneClick 完整包。现有 Steam 启动选项无需重填。

三、创建和加入房间
房主先选择创建房间，进入自己的存档或船上并保持游戏运行。客机随后选择加入房间。
客机使用第三档案位接收房主进度；替换前会备份原有第三档案位。首次加入前请用该 Steam 账号正常启动游戏一次以创建档案。
客机进入后等待自动接档，不要手动点继续或载入本地存档。上方会显示连接、加载及等待提示。

局域网、热点、虚拟组网
两端先连到同一个网络，在首屏选择对应网卡；客机点「局域网自动找房」。也可直接输入房主的虚拟 IP。
找不到时确认房主已创房、所选网卡正确，并允许该联机程序通过所用网络的防火墙。

内网穿透（默认独立 TCP）
房主创建 TCP 隧道，本地地址 127.0.0.1，本地端口 38479。不需要开启 HTTPS 或绑定 HTTPS 子域名。
把隧道的公网域名:公网端口发给客机，例如 room.example:54321。客机填入地址栏，HTTPS 不勾选；会自动配对，无需另找房间标识。
首屏网卡选择不决定穿透地址。地址历史会保存在各自电脑，下次可从下拉框选择。
UDP 为可选：另建 UDP 隧道到 127.0.0.1:38479，把公网 UDP 域名:端口填入客机 UDP 栏。独立 TCP 模式留空会自动探测同一公网地址与端口的 UDP，失败继续走 TCP。

保留的 HTTP/HTTPS 入口
旧 HTTP/HTTPS 服务使用 TCP 38477，不是独立 TCP 的 38479。HTTPS 隧道须有有效证书，客机勾选 HTTPS。
房主暂停时可打开「HTTPS 邀请」，填写该 HTTPS 公网地址并复制邀请，客机粘贴到地址栏。邀请五分钟有效。
仅给出局域网搜房用途的端口：UDP 38478。不要把它当作游戏状态端口填写。

四、游戏内操作
直接使用原版头像、数字键、框选和技能栏。已被另一人选中的船员不能同时控制；换人后释放空闲船员。
客机首次入关会选中已分配的船员。只有一名船员时，未获得控制的一方可旁观，双方可交接控制。
快进由房主控制，客机跟随房主速度；客机本地快进按键和按钮已禁用。单人训练不受此限制。
F6：客机在主菜单重连上次房间。F11：断开联机。F7：恢复房主联机（主菜单或任务中均可；正在加载时请等待完成）。F8 留给原版读档，不再触发联机动作。
影子模式进入、退出和执行走同步流程。训练甲板各自进行，有人在训练时暂停选关，回船后恢复联机。
已移除右侧联机选人列表、坐标、控制权计数等调试界面。保留必要的上方等待提示、主菜单重连和暂停时邀请。

五、反馈测试问题
退出后客机通常会自动在下载文件夹生成 Coop-Guest-日期-编号.zip；若没有，运行 ShadowGambitCoop/Collect-Guest.cmd。
房主运行 ShadowGambitCoop/Collect-Host.cmd（或「收集房主测试结果.cmd」）。命令会显示结果路径。
发送两端日志，并描述谁操作、关卡、角色、技能和复现步骤；最好在再次启动前收集。
主日志：BepInEx/LogOutput.log。启动记录：ShadowGambitCoop/session-next/runtime/steam-launch/。
日志可能包含本机路径、时间和网络诊断；分享前可检查内容。不要公开发送整个游戏目录或个人存档目录。

六、单人游戏
使用启动窗口中的「单人游戏」，它会停用本次联机自动连接。只清空 Steam 启动选项并不会移除已安装的插件。
如果要完全停用框架，退出游戏后将游戏根目录的 winhttp.dll 改名为 winhttp.dll.disabled，并清空 Steam 启动选项；恢复时改回文件名并重新设置入口。

本轮主要验证
- 扎甘 D 定身保持期间不反复重播受击动画，结束后恢复正常。
- 首次入关客机实际选中获分配船员，不出现看不见的二号位占用。
- 客机无法自行快进；房主快进时双方仍跟随。中英界面、安装及日志收集可正常使用。
已通过编译、接口核对及自动化检查；本版以上改动仍等待真实双机测试。

端口兼容
新版默认独立 TCP 和 UDP 均为 38479；HTTP/HTTPS 仍为 TCP 38477。旧 UDP 38477 继续接受连接。
TCP 和 UDP 隧道仍须分别建立，公网端口由服务商分配；不同则填写 UDP 地址。只开 TCP 仍能正常连接。

本轮性能优化
- 进入可操作任务后，不再反复全场景搜索选人、登陆点、主菜单和船上专用对象；保留初始化、换场景和回船查询。
- 合并原生 TCP 小报文的分段写入；大存档保留分开写入，避免额外整份复制。传输格式和状态字段保持兼容。
- 未降低角色、敌人和技能状态的同步频率。实际帧率和延迟改善仍需在相同电脑、场景和网络下对照测试。
- 同一原生 TCP 通道复用后端本机连接；空闲后重新建立，异常时不自动重发可能已执行的操作。

接档重试修复
修复接档未完成就退出重进时，旧临时桥接地址失效而无法取消房主等待的问题。已验证的新连接仅用于取消同一房间的旧请求，不会把取消发给另一个房间。
接档集成检查：原生 TCP 21 项、HTTP 16 项；另有 22 项取消目标边界检查与 1 项真实失效旧桥恢复检查通过。原生游戏事件仍使用测试替身，实际双机游戏继续按测试版核对。
